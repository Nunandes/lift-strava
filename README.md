# Lift → Strava

Bringt Krafttrainings aus Alpha Progression mit Muskelgruppen zu Strava.

1. Alpha Progression: Export → Workouts (CSV) in Dateien sichern
2. App öffnen, CSV wählen
3. FIT-Datei sichern und auf strava.com/upload/select hochladen
4. Titel und Beschreibung kopieren und einfügen

Läuft komplett im Browser, keine Daten verlassen das Handy (ausser beim Strava-Upload).
